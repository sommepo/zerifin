# Zerifin and upstream Jellyfin

Zerifin is an independent modified version of Jellyfin for Android. It is not an official Jellyfin
release and is not maintained by the Jellyfin project.

The original project is https://github.com/jellyfin/jellyfin-android. Its Git history, license and
existing copyright notices are retained. The green Zerifin logo derives from Jellyfin's app artwork.
The Android namespace and application IDs remain compatible with the existing codebase; those
technical identifiers do not imply upstream endorsement.

Zerifin additions include interactive Japanese subtitle lookup, local dictionary/frequency imports,
word pronunciation, multimedia AnkiDroid mining, learning settings and optional server-resolved
YouTube playback. The application source is distributed under the GNU General Public License,
version 2; see LICENSE.md. Dependencies retain their respective licenses and acknowledgements.

This source repository does not bundle dictionary archives, pronunciation recordings, YouTube
media, a YouTube account, an Anki collection or release signing keys.
